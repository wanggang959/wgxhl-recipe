# 王师傅家生活助手微信小程序

使用微信开发者工具导入本目录；项目已设置小程序 AppID。当前功能已与网页端基本对齐：

- 账号密码登录、游客浏览公共菜谱、邮箱验证码 / 邀请码注册；
- 首页家庭 / 公共菜谱、搜索、分类、排序、收藏、点赞；
- 菜谱详情、收藏 / 想吃 / 点赞、本人编辑和删除、王师傅下架 / 恢复；
- 收藏页、想吃页（日期切换、改期、移除、通知家人备菜）；
- 菜谱新增 / 编辑：封面与步骤图上传、食材 / 调料选择与快速新建、步骤增删改排序；
- 采购汇总：按时间范围汇总食材和调料、标记已够 / 待购、生成采购待办；
- 家庭待办、待办详情、通知中心、家庭与成员管理、邮箱安全、密码修改、通勤记录、专项开支、基础数据。
- 找回密码可申请重置邮件，并粘贴邮件中的链接完成重置；邀请码支持复制网页邀请链接。
- 菜谱图片支持微信裁剪，专项开支支持生成并保存清单长图。
- 系统概览及用户管理仅在服务端确认平台管理员权限后开放。

支持账号密码登录并绑定微信，绑定后可使用微信登录。仍不包含微信订阅消息或小程序内支付；提醒目前走站内通知、邮件和网页端 PWA 推送。系统管理中的通知记录与人工补发暂未接入小程序。

微信登录需先在后端数据库执行 `backend/sql/add_wechat_binding.sql`，并配置 `WECHAT_MINIAPP_APP_ID` 和 `WECHAT_MINIAPP_APP_SECRET`。密钥仅配置在服务器，不要提交到仓库或提供给小程序。首次绑定时可在登录页勾选“登录并绑定当前微信”，或登录后在“我的 → 账号 → 微信绑定”中绑定、查看状态或验证密码后解绑；微信登录不会自动创建账号。修改部署配置后需重启后端并验证真实微信登录。

当前 `config.js` 已按项目所有者要求指向生产服务，用于登录和读取联调。登录会访问真实账户并可能产生安全日志，其他业务操作开发完成前应先确认影响。需要隔离测试时改为独立测试后端 HTTPS 地址，格式为 `https://example.com/recipe`。须在微信后台配置对应 request 合法域名。请勿提交账号密码或 AppSecret。正式版不可依赖开发工具中关闭域名校验；域名资质与备案要求需按微信后台核实。

在本目录执行 `node --test tests/*.test.js` 运行基础测试。体验版和正式审核需在微信开发者工具及管理后台操作。
